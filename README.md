# 工业园区资产管理系统（本地原型）

纯本地、零外部依赖、数据不出园区的演示/参考实现。

## 启动

**方式一（推荐，一键后台启动，关掉终端也不中断）：**

```bash
cd park-admin-system
bash start.sh
```

脚本会自动检测 8000 端口、已在运行则直接复用、否则后台拉起并记录日志到 `/tmp/park_backend.log`。

**方式二（前台运行，Ctrl+C 退出）：**

```bash
cd park-admin-system
python3 backend.py
```

然后浏览器打开 http://localhost:8000

- 仅用 Python 标准库（http.server + sqlite3），**无需 pip install、无需联网、无需数据库服务**。
- 数据全部存在本地 `park.db` 文件，清空即重置。
- 想换端口：`PORT=9000 python3 backend.py`
- **注意**：后端不会随电脑/会话重启自动启动。每次要用前先确认 http://localhost:8000 能打开，打不开就跑一遍 `bash start.sh`。
- 想开机自启（macOS）：把 `com.park.admin.plist`（见下）放到 `~/Library/LaunchAgents/` 并 `launchctl load`，登录后自动拉起。

## 功能模块

| 模块 | 说明 |
|------|------|
| 看板 | 出租率、去化率、空置、欠费、收缴率、营收趋势、工单统计 |
| 资产台账 | 楼栋→单元三级，状态（空置/在租/在售/已售…）实时联动合同 |
| 公寓管理 | 公寓专用：总公寓数、到期预警（30/15/7 天）、续租、退租结算、押金台账、空置追踪 |
| 厂房管理 | 厂房统一入口：厂房总数 / 在租 / 空置 / 可售 / 已售 / 回款进度；标签页切换「厂房租赁」与「厂房销售」 |
| 客户 | 企业 / 个人两类客户 |
| 合同 | 销售 / 租赁两套模板，签约后自动联动资产状态 |
| 收费 | 租金 / 物业费 / 水电 / 房款账单；收款登记；公寓抄表自动出水电账单；一键生成月账单；押金收退 |
| 工单 | 报修 / 巡检，派单→处理→完成→评价 |

## 收费规则（已内置）

- 厂房租赁 → 租金 + 物业费（按面积）
- 厂房销售 → 房款（分期回款）+ 物业费（过户后业主交）
- 公寓租赁 → 租金 + 水电费（按表、月结）

## 角色演示

右上角可切换角色，按权限显示/隐藏操作按钮：
系统管理员（全权限）/ 招商专员（资产+客户+合同+公寓/厂房租期续租退租）/ 财务（收费+收款+抄表+押金）/ 物业（工单）/ 园区领导（只读看板+厂房管理视图）。
